# Simulaciones de excitabilidad neuronal

Repositorio con códigos de definición y simulación numérica de modelos matemáticos de excitabilidad neuronal, desarrollados en el contexto de una tesis.

## Contenido del repositorio

### 1. Comparación de modelos FHN

Directorio: `FHN-comparacion/`

- `FHN_comparacion_Definicion.py`: definición del modelo y funciones auxiliares.
- `FHN_comparacion_Simulacion.ipynb`: cuaderno de Jupyter para el análisis y la comparación de los modelos FHN-Basal y FHN-Cortisol.

### 2. Modelo HH-Barrett

Directorio previsto: `HH-Barrett-Simulacion/`

En este directorio se incorporarán los archivos de definición y simulación correspondientes al modelo HH-Barrett.

## Requisitos

El código utiliza Python y bibliotecas científicas. Las dependencias y sus versiones se documentarán una vez comprobado el entorno de ejecución.

Algunas figuras pueden requerir una instalación de LaTeX para su representación mediante Matplotlib.

## Ejecución

Las instrucciones específicas para instalar las dependencias y ejecutar los cuadernos se añadirán después de comprobar su funcionamiento en un entorno limpio.

## Reproducibilidad

El objetivo de este repositorio es facilitar la consulta del código y la reproducción de los análisis numéricos presentados en la tesis. Los resultados deben interpretarse de acuerdo con las ecuaciones, los parámetros y las condiciones iniciales especificados en cada simulación.

## Estado del proyecto

En preparación. La estructura, las dependencias y las instrucciones de ejecución están sujetas a revisión.
